# @yuki-byte18/server

只读报告服务：把 `.perfpilot/` 下的运行产物通过 HTTP 暴露出来，同时托管 `@yuki-byte18/web` 构建好的报告页。

```
GET /healthz
GET /api/runs                     运行记录列表
GET /api/runs/:id                 单次运行的完整数据（诊断 / 候选 / 决策 / 验证）
GET /api/runs/:id/report          该次运行的 Markdown 报告
```

## 它只读

**不触发采集、不执行改动、不写任何东西。** 一旦服务端能触发运行，它就同时成了新的攻击面，以及"为什么 CI 里跑了两遍"的来源。

默认只监听 `127.0.0.1`：报告里含内部 URL、资源体积与源码位置，默认对外暴露并不合适。要暴露到内网必须显式传 `--host 0.0.0.0`，此时**也应该**同时设置 `PERFPILOT_TOKEN` —— 没设会在启动时明确警告，而不是安静地裸奔。

找不到报告页构建产物时它只提供 API，并且在访问 `/` 时直接告诉你缺的是哪一步，而不是给一个裸 404。

## 安装

一般不需要单独安装 —— `perfpilot serve` 会用它。
