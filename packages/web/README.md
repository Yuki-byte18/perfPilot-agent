# @yuki-byte18/web

`perfpilot serve` 托管的报告页 —— React + Vite 构建出来的**静态产物**。

五个视图：总览、指标、诊断（证据与归因）、优化（补丁与检查结果）、趋势。数据全部来自 `/api/*`，这一页本身不做后端渲染；运行记录按 `route | device` 分组选择，同一分组内才能比较指标。

诊断视图会标出每个瓶颈的来源（规则 / 🤖 LLM）、置信度与证据；优化视图给出每个候选的补丁、期望收益与检查结果，以及它最终是"保留"还是"回滚"。

## 只发布 `dist/`

发到 npm 的就是构建产物：`dist/index.html` + `dist/assets/*`。源码里的 React 只用于**构建**，所以它在 `devDependencies` —— 消费者为了一个已经构建好的静态页不该再装一遍 React。

本包**故意不声明 `exports` / `main`**：这样 `@yuki-byte18/cli` 才能解析 `@yuki-byte18/web/package.json` 来定位报告页目录（源码树布局与 npm 安装布局都要能找到）。

## 体积预算有守卫

这一页自身的首屏预算写在 `src/perf.test.ts` 里，它检查的是**决定 LCP 与 CLS 的结构**，不是编一个数字：无外链样式表、无 web font、无图片、挂载点已在 HTML 中、运行时依赖必须为空、构建期依赖必须命中白名单 —— 想加任何新依赖，都得先回答"它对首屏值多少"。
